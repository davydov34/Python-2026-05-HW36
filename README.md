## Домашнее задание 36 - Crawler

*Задание*: рпознакомиться с асинхронным программированием и получить опыт написания и отладки асинхронных программ.

#### Описание:
В этом домашнем задании предлагается реализовать асинхронный краулер для новостного сайта news.ycombinator.com. Предполагается, что краулер запускается каждые N секунд, парсит топ новостей, сохраняя каждую, а также сохраняет все ссылки из обсуждения конкретной новости.

#### Используемые зависимости:
1. Для выполнения асинхронных запросов к ресурсу и получения html страницы для разбора была использована асинхронная библиотека **aiohttp**;
2. Парсинг полученной страницы происводился посредством библиотеки **BeautifulSoup**;
3. Обработчиком html страницы для BeautifulSoup выступал высокопроизводительная библиотека **lxml**.


#### Запуск приложения:
Приложение может быть запущено в конфигурации по умолчанию:
```bash
python3 main.py
```
В данном случае в качестве параметров запуска будут использованы значения по умолчанию - 30 секунд в качестве интервала между обращениям к ресурсу и именем директории "parsing_data".

Собтсвенные значения времени и наименования директории могут быть переданы через параметры "-t" или "--time" для времени и "-d" или "--dir" для директории:

```bash
python3 main.py -t 5 -d 'custom name directory' 
```

Через выбранный при запуске интервал, происходит запрос к ресурсу, получение html документа, его разбор и сохранение JSON-файла в указанную при запуске директорию.
